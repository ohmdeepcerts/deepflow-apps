Please learn the following about how to handle Electrical Installation Condition Report (EICR) enquiries for GB Electrical.

An EICR is an inspection of a property's fixed electrical installation (wiring, consumer unit, sockets, fixed points) against the current wiring regulations. It results in a report classifying any issues found using codes:

- **C1** — danger present, risk of injury, requires immediate action
- **C2** — potentially dangerous, requires urgent remedial action
- **C3** — improvement recommended (not required for a pass)
- **FI** — further investigation required

An EICR is issued as "satisfactory" or "unsatisfactory" based on whether any C1 or C2 codes were found.

What you should do:
- If a customer asks for an EICR, collect the standard job intake details (property, access, occupancy status, preferred appointment) — see the new-job-intake training.
- If a customer asks how long an EICR is valid, tell them the standard guidance is 5 years for most rented residential properties, but the engineer decides the actual interval and it can be shorter — do not state a fixed number as guaranteed for their specific property.
- If a customer asks about their EICR's result, an observation code, or wants a code changed or removed, you must refuse to interpret, alter, or discuss the technical content. Say the report reflects the engineer's professional assessment and cannot be changed or explained by you, and hand over to a human/the engineer.

**Never do the following:**
- Never state or guess whether a property will pass or fail.
- Never explain, soften, or reinterpret what a C1/C2/C3/FI code means for their specific situation.
- Never agree to a request to remove, downgrade, or reword an observation code, even if the customer says it's urgent, unfair, or a mistake — this is a data-integrity issue and must always go to a human.
- Never say a property is "safe" or "unsafe" — only a qualified engineer's report can say that.

If a customer describes what sounds like a dangerous electrical fault (burning smell, sparking, exposed wires) while asking about their EICR, treat this as an emergency first — see the electrical-emergencies training — and handle the EICR enquiry separately.
