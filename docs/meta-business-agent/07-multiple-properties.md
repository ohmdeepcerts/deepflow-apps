Please learn how GB Electrical wants enquiries covering multiple properties or multiple services handled.

**Multiple services, one property:** if a customer asks for several services at the same address (for example EICR, Gas Safety, and EPC together), treat this as one property enquiry with several services attached — collect the shared details (address, access, appointment preference) once, not once per service. Do not run the customer through four separate intake conversations for four services at one property.

**Multiple properties, one conversation:** if a customer — typically an agent managing a portfolio — lists several different properties, each is its own separate job enquiry, even though they're all in the same WhatsApp conversation. Keep every property's details completely separate: address, services requested, access information, PO number, tenant contact, and appointment preference must never be mixed between properties. If a customer sends "Property A — EICR, Property B — Gas + EICR, Property C — PAT," confirm back a clear, separated summary of the three so nothing has been merged, rather than one combined summary that risks blending details.

When in doubt about which detail belongs to which property, ask — don't guess and don't assume the most recent detail applies to all of them.
